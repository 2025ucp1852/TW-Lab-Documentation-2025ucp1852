\section{Introduction}

The picture environment is used to create simple
drawings and diagrams directly in LaTeX.

It provides commands for drawing lines, vectors,
circles, boxes, and other graphical elements.

\section{Setting the Unit Length}

The unit length determines the size of coordinates
used inside the picture environment.

\setlength{\unitlength}{1cm}

\section{Drawing Lines}

The line command draws a straight line.

\begin{center}
\begin{picture}(6,2)
    \put(0,1){\line(1,0){5}}
    \put(0,1.3){Horizontal line}
\end{picture}
\end{center}

\section{Drawing Vectors}

The vector command draws a line with an arrowhead.

\begin{center}
\begin{picture}(6,3)
    \put(0,0){\vector(1,1){3}}
    \put(3.2,2.5){Vector}
\end{picture}
\end{center}

\section{Drawing Circles}

The circle command draws an unfilled circle.
The circle* command draws a filled circle.

\begin{center}
\begin{picture}(7,3)
    \put(1,1.5){\circle{2}}
    \put(4,1.5){\circle*{2}}
    \put(0,0){Unfilled circle}
    \put(3,0){Filled circle}
\end{picture}
\end{center}

\section{Drawing an Oval}

The oval command creates an oval-shaped outline.

\begin{center}
\begin{picture}(6,3)
    \put(0.5,0.5){\oval(5,2)}
\end{picture}
\end{center}

\section{Drawing a Frame Box}

The framebox command creates a rectangular box.

\begin{center}
\begin{picture}(6,2)
    \put(0.5,0.5){\framebox(4,1){LaTeX Picture}}
\end{picture}
\end{center}

\section{Using the Makebox Command}

The makebox command creates a box for positioning
text inside the picture environment.

\begin{center}
\begin{picture}(6,2)
    \put(0.5,0.5){\makebox(4,1){Technical Writing Lab}}
\end{picture}
\end{center}

\section{Drawing Repeated Objects}

The multiput command repeats an object at regular
coordinate intervals.

\begin{center}
\begin{picture}(7,2)
    \multiput(0,0.5)(1.5,0){5}{\circle*{0.3}}
\end{picture}
\end{center}

\section{Conclusion}

The picture environment provides basic drawing
facilities in LaTeX. It is useful for simple diagrams,
geometrical illustrations, and labelled drawings.
