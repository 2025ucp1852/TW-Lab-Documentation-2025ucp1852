# Google Docs Documentation – TW Lab 2026

## 1. Introduction

Google Docs is a web-based word-processing application developed by Google. It allows users to create, edit, format, store, and share documents online. Multiple users can work on the same document simultaneously.

## 2. Learning Objectives

- Understand the Google Docs interface.
- Create and edit documents.
- Apply text and paragraph formatting.
- Insert tables, images, and other elements.
- Configure page layout and document settings.
- Use sharing and collaboration features.

## 3. Creating a Document

1. Open [Google Docs](https://docs.google.com/).
2. Sign in with a Google account.
3. Click **Blank document** to create a new document.
4. Enter a suitable document title.
5. Start typing in the document area.
6. Google Docs automatically saves changes to Google Drive.

## 4. Text Formatting

Google Docs provides several text-formatting options.

- **Bold:** Makes text darker and thicker.
- *Italic:* Makes text slanted.
- Underline: Adds a line below text.
- Font style: Changes the appearance of text.
- Font size: Adjusts the size of text.
- Text color: Changes the font color.
- Highlight color: Highlights selected text.

## 5. Paragraph Formatting

Paragraph formatting helps organize document content.

- Text alignment: Left, center, right, and justified.
- Line spacing: Controls the space between lines.
- Paragraph spacing: Adjusts space before and after paragraphs.
- Bulleted lists: Organizes information using bullets.
- Numbered lists: Organizes information using numbers.
- Indentation: Changes the position of paragraphs.

## 6. Headings and Styles

Google Docs provides predefined text styles to organize documents.

- Title
- Subtitle
- Heading 1
- Heading 2
- Heading 3
- Normal text

Using heading styles helps create a consistent document structure and allows automatic table-of-contents generation.

## 7. Inserting Tables and Images

### 7.1 Tables

Tables organize information into rows and columns.

Steps:
1. Open the **Insert** menu.
2. Select **Table**.
3. Choose the required number of rows and columns.
4. Enter information into the table cells.

### 7.2 Images

Steps:
1. Open the **Insert** menu.
2. Select **Image**.
3. Choose an image source, such as Upload from computer or Drive.
4. Insert the image.
5. Resize and position it as required.

## 8. Page Setup

Page setup controls the overall appearance of a document.

Important options include:

- Page orientation: Portrait or Landscape.
- Paper size: A4, Letter, and other available sizes.
- Margins: Top, bottom, left, and right.
- Page color: Changes the page background color.

These settings can be accessed through **File → Page setup**.

## 9. Headers, Footers and Page Numbers

Headers and footers display repeated information at the top and bottom of pages.

Steps:
1. Open the **Insert** menu.
2. Select **Page elements** or the relevant header/footer option.
3. Choose Header or Footer.
4. Enter the required information.

To insert page numbers, use **Insert → Page numbers** and select a suitable layout.

## 10. Collaboration and Sharing

Google Docs supports real-time collaboration.

- Share documents with other users.
- Assign Viewer, Commenter, or Editor permissions.
- Add comments and suggestions.
- View document changes.
- Use version history to review previous versions.

To share a document, click the **Share** button and enter the email addresses of the intended users.

## 11. Downloading and Exporting

Google Docs supports downloading documents in several formats.

Steps:
1. Open the **File** menu.
2. Select **Download**.
3. Choose the required format.

Common formats include:
- Microsoft Word (.docx)
- PDF Document (.pdf)
- Plain Text (.txt)
- Rich Text Format (.rtf)
- EPUB Publication (.epub)

## 12. Practical Applications

Google Docs is useful for creating:

- Academic reports and assignments.
- Project documentation.
- Resumes and cover letters.
- Meeting notes.
- Collaborative research documents.
- Technical documentation.
